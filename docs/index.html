How it works · 工作原理

四阶段流水线

STAGE 01

LLM 剧本导演

把一句话扩写为角色设定 + N 个竖屏分镜剧本（本地 Qwen3.5 或任意 OpenAI 兼容云端模型）。

STAGE 02

角色定妆

Z-Image turbo 为每个角色生成定妆图，此后全片共用同一张参考图保证人设一致。

STAGE 03

逐镜头成片

MiniMax H3 ref2va 逐镜头生成竖屏视频与原生音频，单镜头完成后即释放显存。

STAGE 04

自动拼接

ffmpeg 拼接全部镜头并输出 final_drama.mp4，支持断点续跑与剧本复查。

Features · 特性

为“一句话拍剧”打磨到开箱即用

🎬角色一致性

全部镜头共用同一张定妆参考图（<Picture 1>），主角外观全程不漂移。

♾️时长不设限

镜头数由剧本决定，目标时长 ≥90s 自动分幕扩写，逐镜头循环 + 断点续跑。

🧠剧本审查 / AI 审核

生成剧本可预览确认，也支持接入云端大模型按你的要求自动改进剧本。

🔉原生音频

视频生成即含声音；可选 edge-tts 为角色加配音，开箱即用。

🖥️GUI + CLI

面向新手的图形界面（向导安装 / 桌面快捷方式）与面向自动化的命令行引擎并存。

💾省显存设计

单镜头独立提交、跑完即释放，16GB 显存（RTX 4060 Ti 级）即可流畅工作。

Quick start · 源码运行

五条命令跑起来

前提：本机已启动 ComfyUI（127.0.0.1:8188），并安装 H3 ref2va / Z-Image turbo / ComfyUI-llama-cpp_vlm 节点与模型。

:: 克隆并安装依赖
git clone https://github.com/admin2221/one-line-drama.git
cd comfyui
python -m pip install -r requirements.txt

:: 一句话直接出片
python factory\drama_factory.py "一个落魄书生在雨夜捡到一枚能穿越时空的古镜"

:: 断点续跑 / 复用剧本 / 打开图形界面
python factory\drama_factory.py "你的故事…" --resume
python factory\drama_factory.py --script-json output\xxx\script.json
python gui\drama_gui.py
💡 拿到 Windows 安装包的最终用户不需要任何命令行：双击 短剧生成器安装向导.exe 即可安装并使用（见「下载」）。

FAQ · 常见问题

你可能想问

需要多大的显卡？
16GB 显存（RTX 4060 Ti 级别）即可顺畅生成。逐镜头提交、跑完释放显存，是为省显存专门设计。
完全免费吗？有激活码吗？
是的。本仓库为完全开源版（MIT）：无激活码、无试用门禁、无水印。云端剧本（可选）按你所填 API 的提供商计费。
生成的视频有声音吗？
MiniMax H3 视频生成自带原生音频；也可开启 --tts 用 edge-tts 添加角色配音。
一定要先装 ComfyUI 吗？
是。本工具是 ComfyUI 的“导演客户端”，需先启动本机 ComfyUI（默认 127.0.0.1:8188）并装有 H3 / Z-Image / llama_cpp 节点与模型。
